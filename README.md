## Project Description

Campus Create is a responsive workshop registration webpage built using HTML, CSS, and JavaScript. It allows users to select a workshop, enter registration details, choose the number of seats, and preview their registration. The project also includes form validation, password confirmation, responsive styling and a reset button

##How to Run the Project

Download or clone the project repository.
Open the project folder called my-registration
Make sure index.html, styles.css, and app.js are in the same folder.
Open index.html in a web browser.
Select a workshop and enter the required details.
Click Preview registration to view the registration result.
Click Reset to clear the form and start again.
